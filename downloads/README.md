## 可选：在自己的Windows电脑尝试官方PDF下载

当前云端不能代表用户电脑的网络状况。以下脚本仅请求Nature/PMC官方PDF地址，并检查文件以`%PDF-`开头；不会把登录页、验证码页或HTML保存成论文PDF，不使用HTML转PDF，不使用学校账号或绕过付费限制。需要访问权限的文章可能仍然失败。

整体下载ZIP后，在`downloads`文件夹双击`Run_PDF_Downloader.cmd`；请与`Download_Original_PDFs.ps1`保存在同一文件夹。它会在桌面创建“骨科学术PDF”，按模块和英文原题保存取得的正文PDF，并生成下载状态CSV和压缩包。若已有同名但内容不同的文件，会保留原文件并报告冲突。CMD启动时仅对该PowerShell进程使用执行策略参数，不修改系统持久设置。

脚本已检查下载逻辑，但尚未在Windows实机运行验证，不能保证获取正文。它不会自动合并`papers`中的附图，请保留该目录。
