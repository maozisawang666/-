# 骨科学术资料库

整理骨科文献阅读、循证医学笔记与科研方法，供学习和学术交流使用。

## 内容规划

- 创伤骨科：骨折分类、治疗研究与康复结局。
- 关节外科：髋膝关节疾病、关节置换与围手术期研究。
- 脊柱外科：退变、创伤与相关临床研究。
- 运动医学：韧带、半月板及肌腱损伤研究。
- 骨科基础研究：骨生物学、生物力学与组织工程。
- 科研方法：文献检索、研究设计、统计分析及论文写作。

## 文献笔记模板

1. 题目、作者、期刊及发表年份。
2. DOI 或原文链接。
3. 研究问题与研究设计。
4. 研究对象、干预或暴露、对照及主要结局。
5. 主要结果：记录效应量、置信区间和随访时间。
6. 偏倚风险、研究局限与适用范围。
7. 个人总结及待解决问题。

## 收录原则

注明资料来源，区分原文结论与个人解读；优先链接合法公开版本，不上传无授权全文或可识别患者的信息。内容仅供学术学习，不作为个体诊疗建议。
